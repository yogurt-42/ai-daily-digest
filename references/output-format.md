# 输出格式

## 骨架

```
【行业新闻】
1. <事件>，<为什么重要>（<来源域名>）
判断：<一句话，≤40 字>
2. …

【GitHub 热门】
<owner/repo> — <解决什么问题> — 今日 +N 星（总计 M 星）
点评：<一句话，≤40 字>

【对你的意义】
<1-2 句，点名具体某条，说清为什么>
```

## 正例

```
【行业新闻】
1. 某厂商开源 30B agent 模型，工具调用基准超过同级闭源，权重可直接商用（github.com）
判断：自托管 agent 多了一个便宜选项，先看它在长任务上的掉线率。

【GitHub 热门】
acme/agent-kit — 把工具调用失败重试和预算控制封成库 — 今日 +820 星（总计 12400 星）
点评：自己写 agent 循环的人能直接省掉重试逻辑，建议读源码。

【对你的意义】
最该看 agent-kit 的重试策略：你现在手写的退避逻辑和它撞了，可以对照着删一半。
```

## 反例

- ❌「某公司发布了新模型，意义重大，值得关注。」——没有信息，没有判断
- ❌「今日 +1.2 万星」——数字没出现在采集结果里
- ❌ 把「据报道」写成确定事实
- ❌ 用表格或加粗（QQ 不渲染）

## 字数和节奏

- 每条控制在一屏内能读完，判断句不铺垫
- 宁短勿长：砍掉形容词，保留动词和数字
